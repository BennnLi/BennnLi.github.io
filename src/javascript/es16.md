## Iterator Helpers

以前只有数组能 `.map` / `.filter`，迭代器只能干瞪眼。现在 `Iterator.prototype` 上也有了一整套。

````javascript
[1, 2, 3, 4, 5].values()
  .filter(x => x % 2 === 1)
  .map(x => x * 10)
  .take(2)
  .toArray()
// [10, 30]
````

`Iterator.prototype` 上一共 11 个方法，按"会不会吃掉迭代器"分成两类：

| 方法 | 返回 | 消费迭代器？ |
|------|------|------------|
| `map(fn)` | 新迭代器 | 否 |
| `filter(fn)` | 新迭代器 | 否 |
| `take(n)` | 新迭代器 | 否 |
| `drop(n)` | 新迭代器 | 否 |
| `flatMap(fn)` | 新迭代器 | 否 |
| `reduce(fn, init)` | 具体值 | 是 |
| `toArray()` | 数组 | 是 |
| `forEach(fn)` | `undefined` | 是 |
| `some(fn)` | `boolean` | 是（命中即停） |
| `every(fn)` | `boolean` | 是（不满足即停） |
| `find(fn)` | 元素 / `undefined` | 是（命中即停） |

前 5 个返回迭代器，**能继续链**；后 6 个是终点，**链到头了**。

````javascript
const seen = []

[1, 2, 3, 4, 5].values()
  .map(x => { seen.push(x); return x })
  .take(2)
  .toArray()

seen    // [1, 2]  ← 后面三个压根没算
````

**两条一次性规则得记住**

① **迭代器只能用一次**，消费掉就空了：

````javascript
const it = [1, 2, 3].values()

it.toArray()    // [1, 2, 3]
it.toArray()    // []        ← 已经耗尽
````

② **同一个迭代器上不能链两条**，两个包装器会抢同一个底层：

````javascript
const it = [1, 2, 3, 4, 5].values()

const a = it.map(x => x * 10)
const b = it.map(x => x + 100)

a.next()    // { value: 10,  done: false }
b.next()    // { value: 102, done: false }  ← 接着 a 的位置，不是从头
a.next()    // { value: 30,  done: false }  ← 两个包装器在抢一个源
````

想在同一个源上走多遍，先 `toArray()` 落成数组，或者每次重新取迭代器。

另外 `Iterator.from` 能把普通可迭代对象包装成迭代器：

````javascript
Iterator.from({ [Symbol.iterator]: function* () { yield 1; yield 2 } }).toArray()
// [1, 2]

new Map([['a', 1]]).entries().map(([k, v]) => k + v).toArray()
// ['a1']
````

> 注意 `Iterator.from` **只认可迭代对象**，类数组（`{ length: 2, 0: 'a' }`）会报 `TypeError`。那种要先用 `Array.from`。

## Set 方法群

集合运算终于内置了，不用再手写循环。

````javascript
const A = new Set([1, 2, 3])
const B = new Set([2, 3, 4])

A.union(B)                 // 取 A 和 B 的并集 Set { 1, 2, 3, 4 }
A.intersection(B)          // 取 A 和 B 的交集 Set { 2, 3 }
A.difference(B)            // 取 A 和 B 不同的部分  Set { 1 }
A.symmetricDifference(B)   // 取 A/B 各自不同的部分 Set { 1, 4 }

A.isSubsetOf(B)            // A 是 B 的子集 false
A.isSupersetOf(B)          // 判断 A 是不是 B 的超集：B 里的每个元素，A 里都有 false
````

两点得注意：

- **都不改原集合**，返回的是新 `Set`（`A`、`B` 的 `size` 不会变）
- **参数必须是 Set-like**，不能直接传数组：

````javascript
A.union([4, 5])
// TypeError: The .size property is NaN
````

## Promise.try()

把"可能同步抛错也可能返回 Promise"的函数包起来，两种错都变成 reject。

````javascript
Promise.try(() => 1)                  // Promise<1>
Promise.try(() => { throw new Error('sync') })
  .catch(e => e.message)              // 'sync'
Promise.try(() => Promise.resolve(2)) // Promise<2>，自动展开
````

跟 `Promise.resolve().then(fn)` 的区别：**`Promise.try` 的回调是同步执行的**。

````javascript
let called = false
Promise.try(() => { called = true })
called    // true  ← 立刻就执行了
````

写库的时候有用 —— 你调别人的回调，不知道它是同步抛错还是返回 rejected Promise，用它包一下就统一了。

## RegExp.escape()

把字符串安全地塞进正则里，不用再手写 `str.replace(/[.*+?^${}()|[\]\\]/g, '\\$&')` 那一长串。

````javascript
RegExp.escape('a.b*c')      // '\\x61\\.b\\*c'
new RegExp(RegExp.escape('a.b*c')).test('a.b*c')   // true
````

注意它的输出有点怪：**第一个字符如果是字母或数字，会被转成 `\xNN`**。

````javascript
RegExp.escape('abc')    // '\\x61bc'   ← a 变成 \x61，后面的不变
RegExp.escape('1abc')   // '\\x31abc'
RegExp.escape('(x)[y]{z}')   // '\\(x\\)\\[y\\]\\{z\\}'
````

这是规范有意为之，为的是让转义结果能安全拼接。反正你不用管，直接套 `new RegExp()` 就行。

## 正则内联修饰符

`i` / `m` / `s` 这几个标志以前只能加在整个正则上，现在可以局部生效。

````javascript
/(?i:abc)/.test('ABC')          // true   这一小段忽略大小写
/(?i:abc)def/.test('ABCdef')    // true
/(?i:abc)def/.test('ABCDEF')    // false  def 那段仍然区分大小写
````

也能取消：

````javascript
/(?-i:abc)/i.test('ABC')        // false  外层 i 被局部取消了
/(?i:a(?-i:b)c)/.test('ABC')    // false  b 必须小写
````

`m` 和 `s` 同理：

````javascript
/(?s:a.b)/.test('a\nb')         // true
````

## 重复具名捕获组

以前同一个正则里不能有两个同名的捕获组。现在**只要不在同一个分支**就可以。

````javascript
/(?<y>\d{4})-(?<m>\d{2})|(?<y>\d{2})\/(?<m>\d{2})/.exec('06/15').groups
// { y: '06', m: '15' }
````

这样写日期解析就舒服了，不用为"两种格式"准备两套组名。

同一个分支里还是不行：

````javascript
new RegExp('(?<x>a)(?<x>b)')    // SyntaxError
````

## Import Attributes 与 JSON 模块

可以在 import 语句后面带属性了，最常见的用法就是直接导入 JSON。

````javascript
import config from './data.json' with { type: 'json' }

console.log(config.name)
````

动态导入也能带：

````javascript
const config = await import('./data.json', { with: { type: 'json' } })
````

`type: 'json'` 这个属性不是摆设 —— 它是**必须的**，浏览器和 Node 都会校验，不写就报错。这么设计是为了安全和语义明确：不用再猜一个 `.json` 到底该当成什么处理。

目前支持的类型就 `json` 和 `css`（CSS 模块还在推进中）。

## Float16Array / Math.f16round

16 位浮点数，主要给机器学习、图形计算这种"精度够用就行、内存要省"的场景。

````javascript
const arr = new Float16Array([1.5, 2.5])
arr.BYTES_PER_ELEMENT      // 2  ← 是 Float32Array 的一半
[...arr]                   // [1.5, 2.5]
````

能表示的整数范围很小，超出就变 `Infinity`：

````javascript
new Float16Array([70000])   // [Infinity]
````

配套还有个舍入函数：

````javascript
Math.f16round(1.1)   // 1.099609375
Math.f16round(0.1)   // 0.0999755859375
````

`DataView` 也加了 `getFloat16` / `setFloat16`，方便按字节操作。

日常业务基本用不上，知道有这东西就行。
