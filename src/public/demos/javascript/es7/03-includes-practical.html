1. 简化多条件 if 判断

// 以前
if (n === 20 || n === 40) { ... }

// 现在
if ([20, 40].includes(n)) { ... }

2. 权限 / 角色白名单

const ADMIN_ROLES = ['owner', 'admin']
if (ADMIN_ROLES.includes(user.role)) { showAdminPanel() }

3. 简易去重（数组字面量版）

const seen = []
for (const id of ids) if (!seen.includes(id)) seen.push(id)
点按钮运行

⚠️ 4. 反例：includes 不能替代 some()

// ❌ 把箭头函数本身当成了"要查找的值"
[1, 20, 30].includes(x => x > 10)   // false

// ✅ 想按条件找，用 some()
[1, 20, 30].some(x => x > 10)       // true
点按钮运行
