await 右边可以是任意值

async function f() {
  const n = await 42       // 42
  const s = await 'hello'  // 'hello'
  const o = await { a: 1 } // { a: 1 }
  const p = await Promise.resolve('来自 Promise')
}
点按钮看看 await 拿到了什么
原理：await expr 内部第一步就是把 expr 交给 Promise.resolve()，所以非 Promise 值也能 await。
但要记住：不论右边是不是 Promise，await 之后的代码都是异步执行的 （见下一个示例 03-execution-order）。
