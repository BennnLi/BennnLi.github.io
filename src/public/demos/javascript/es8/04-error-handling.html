1. try / catch 捕获 await 的失败

async function load() {
  try {
    await fail()            // rejected
  } catch (e) {
    return '降级值'          // ← 会被执行
  } finally {
    log('finally 总会执行')
  }
}
点按钮运行

2. 不捕获 → 变成 unhandledrejection

window.addEventListener('unhandledrejection', e => {
  log('未处理的拒绝：' + e.reason.message)
})
点按钮运行

3. 同步抛错也能被同一个 catch 捕获

async function f() {
  try {
    throw new Error('同步抛错')
    await something()       // 根本执行不到
  } catch (e) { ... }
}
点按钮运行
