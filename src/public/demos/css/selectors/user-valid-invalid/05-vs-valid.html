:user-valid vs :valid 对比 — 理解匹配时机的差异

:valid / :invalid — 页面加载时就匹配

input:valid { border-color: green; } input:invalid { border-color: red; }

注意：页面一加载，空的输入框就显示红色边框（:invalid 状态）

:user-valid / :user-invalid — 用户交互后才匹配

input:user-valid { border-color: green; } input:user-invalid { border-color: red; }

注意：页面加载时，输入框保持默认样式，只有用户输入后才显示验证状态
