:has() 空状态处理 — 用 :not(:has(...)) 判断"空"，无需 JS 检查子元素

1. 空列表自动隐藏

.hide-when-empty:not(:has(li)) { display: none; }

有内容
  • 项目一
  • 项目二
空列表 → 整个元素被隐藏

    ↑ 上面这个空 ul 因为 :not(:has(li)) 而被 display:none 隐藏了。

    2. 空容器显示占位提示

    .list-box:not(:has(> *))::after { content: '暂无数据'; }

    • 有数据时显示正常内容
    • 边框是绿色的

    ↑ 空的容器自动显示「暂无数据」占位文字。

    4. 三态切换（容器有/无内容）

    .state-box:has(> *) { border-style: solid; }　.state-box:not(:has(> *)) { border-style: dashed; }

    有内容态

    边框变实线、蓝色，内容左对齐。

    （空态：虚线边框，居中）

    5. 搜索无结果提示

    .search-results:not(:has(.result))::before { content: '没有匹配的结果…'; }

    匹配结果 1：CSS :has() 选择器
    匹配结果 2：关系型伪类
    价值：以前"列表为空就显示占位图"需要 JS 判断 children.length === 0 再切换 DOM 或类名。:not(:has(...)) 让空状态完全由 CSS 表达，数据层只管渲染数据，空态样式自动生效。
