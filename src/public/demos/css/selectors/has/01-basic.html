:has() 基础用法 — 反向匹配：根据子元素来决定父元素的样式

1. 根据是否含图片选择卡片

.card:has(img) { border-color: #1a73e8; }

这张卡片含图片，所以有蓝色边框和「含图片」标签。

这张卡片没有图片，保持默认样式。

2. 只匹配直接子元素 >

.box:has(> img) { background: #e8f5e9; }

图片是直接子元素 → 绿色背景（匹配）

图片被包在 div 里，不是直接子元素 → 默认样式（不匹配）

3. 根据子元素状态选择父元素

.list:has(.active) { background: #fff3cd; }

  • 项目一
  • 项目二（active）
  • 项目三

↑ 列表中含 .active → 整个列表高亮

  • 项目一
  • 项目二
  • 项目三

↑ 列表中没有 .active → 保持默认样式

核心思想：以前只能"从父选子"，:has() 让 CSS 可以"从子选父"——这正是它被称为「父选择器」的原因。
