:has() vs JavaScript — 同样的效果，一行 CSS 对比一段 JS

代码对比：给「含图片的卡片」加样式

JavaScript 方案 以前的写法

// 1. 遍历所有卡片
document.querySelectorAll('.card').forEach(card => {
  // 2. 检查是否含图片
  if (card.querySelector('img')) {
    // 3. 手动加类名
    card.classList.add('has-image');
  }
});

// 4. 还要监听 DOM 变化，
//    否则动态插入的卡片不会被处理
new MutationObserver(() => {
  document.querySelectorAll('.card').forEach(card => {
    card.classList.toggle(
      'has-image',
      !!card.querySelector('img')
    );
  });
}).observe(document.body, {
  childList: true, subtree: true
});

CSS 方案 :has() 写法

/* 一行搞定，无需 JS */
.card:has(img) {
  border: 2px solid #28a745;
  background: #f8fff8;
}

.card:has(img)::before {
  content: '✓ 含图片';
  color: #28a745;
}

/* 动态插入的元素自动生效
   浏览器原生处理，无需监听 */
优势：没有初始化的遍历开销、没有 MutationObserver、没有类名污染，浏览器原生引擎直接处理，动态 DOM 变更自动重算。
