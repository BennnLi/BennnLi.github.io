:has() 兄弟组合器 — :has(+ x) 看紧邻的下一个兄弟，:has(~ x) 看后面任意兄弟

1. :has(+ li) — 最后一项不加分隔线

.sibling-list li:has(+ li) { border-bottom: 1px solid #eee; }

  • 第一项（后面还有项 → 有分隔线）
  • 第二项（后面还有项 → 有分隔线）
  • 第三项（后面还有项 → 有分隔线）
  • 第四项（最后一项 → 无分隔线，绿色背景标记）

2. h3:has(+ p) — 后面是段落时收紧间距

h3:has(+ p) { margin-bottom: 4px; }　h3:not(:has(+ p)) { margin-bottom: 24px; }

后面紧跟段落的标题

标题和本段落间距很紧凑，因为它们是"标题 + 说明"的组合。

后面不是段落的标题

一个 div 块

3. :has(~ .highlight) — 后面有高亮项时加标记

.item:has(~ .highlight) { border-left: 3px solid #ffc107; }

项目一（后面有高亮项 → 黄色左标记）
项目二（后面有高亮项 → 黄色左标记）
项目三（高亮项本身）
项目四（后面没有高亮项 → 无标记）

4. 步骤条连接线

.step:has(+ .step)::after { content: ''; width: 60px; height: 2px; }

1
2
3
4

连接线由 :has(+ .step) 生成——最后一个步骤后面没有兄弟，所以不画线。

5. label 与 input 的兄弟关系

label:has(+ input:required)::after { content: ' *'; color: #dc3545; }

技巧：只需给 input 加 required 属性，label 上的红色星号就会自动出现——无需在 HTML 里手写星号，也无需 JS 同步。
