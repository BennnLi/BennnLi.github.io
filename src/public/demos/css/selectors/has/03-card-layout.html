:has() 卡片条件布局 — 同一个组件类，根据内容自动切换布局

根据内容自动适配的卡片

.card:has(img) { display: grid; padding: 0; }　.card:not(:has(img)) { border-left: 4px solid #28a745; }

有图片的卡片

自动切换为上下布局，图片撑满顶部。

CSS 布局

纯文字卡片

没有图片，保持内边距布局，左侧显示绿色标记条。

可点击卡片

含链接的卡片会显示悬停效果。
