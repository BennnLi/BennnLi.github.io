:is() vs :where() 特异性对比 — 理解特异性差异

特异性对比演示

:is(.container) p — 特异性 (0,1,0) — 红色（胜出）

:is(.container) p { color: red; }

:where(.container) p — 特异性 (0,0,0) — 绿色（被 p { color: green; } 覆盖）

:where(.container) p { color: blue; }

p { color: green; } ← 这条规则胜出

特异性规则

  • :is() 的特异性 = 参数中最高的特异性
  • :where() 的特异性 = 0（始终为 0）
  • 普通选择器 p 的特异性 = (0,0,1)
