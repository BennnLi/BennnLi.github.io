:nth-child(of S) 奇偶选择 — 在特定类中选中奇偶元素

传统 :nth-child() — 所有奇数行变色

li:nth-child(odd) { background: #ffcdd2; }

  • 项目 1（奇数 - 变色）
  • 项目 2（偶数）
  • 项目 3（奇数 - 变色）
  • 项目 4（偶数）
  • 项目 5（奇数 - 变色）

新语法 :nth-child(of S) — 只对 .visible 奇数行变色

li:nth-child(odd of .visible) { background: #c8e6c9; }

  • 项目 1（visible 奇数 - 变色）
  • 项目 2（visible 偶数）
  • 项目 3（hidden - 跳过）
  • 项目 4（visible 奇数 - 变色）
  • 项目 5（visible 偶数）
