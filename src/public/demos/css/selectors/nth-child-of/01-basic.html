:nth-child(of S) 基础 — 在特定类中选中第 N 个元素

传统 :nth-child() — 选中第 2 个 li

li:nth-child(2) { background: #ffcdd2; }

  • 第 1 个 li
  • 第 2 个 li（选中）
  • 第 3 个 li
  • 第 4 个 li

新语法 :nth-child(of S) — 选中第 2 个 .active 的 li

li:nth-child(2 of .active) { background: #c8e6c9; }

  • 第 1 个 li
  • 第 2 个 li
  • 第 3 个 li
  • 第 4 个 li（选中）
