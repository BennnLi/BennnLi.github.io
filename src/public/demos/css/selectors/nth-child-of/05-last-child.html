:nth-child(of S) 最后 N 个 — 选中最后 N 个特定元素

1. 选中最后 1 个 .visible

.visible:nth-last-child(1 of .visible) { border-bottom: none; background: #c8e6c9; }

  • 项目 1
  • 项目 2
  • 项目 3（hidden）
  • 项目 4（最后 visible - 选中）
  • 项目 5

2. 选中倒数第 2 个 .item

.item:nth-last-child(2 of .item) { margin-bottom: 0; background: #bbdefb; }

  • 项目 1
  • 项目 2
  • 项目 3（倒数第 2 - 选中）
  • 项目 4
  • 项目 5
