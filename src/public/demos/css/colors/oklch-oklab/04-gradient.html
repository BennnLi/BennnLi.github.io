oklch() 渐变 — oklch() 在渐变中的应用

1. 线性渐变

background: linear-gradient(90deg, oklch(0.7 0.2 250), oklch(0.7 0.2 350));

2. 径向渐变

background: radial-gradient(circle, oklch(0.7 0.2 250), oklch(0.7 0.2 350));

3. 锥形渐变 — 色环

background: conic-gradient(oklch(0.7 0.2 0), oklch(0.7 0.2 60), ...);

用 oklch() 生成的色环，颜色过渡更平滑、更符合人眼感知。
