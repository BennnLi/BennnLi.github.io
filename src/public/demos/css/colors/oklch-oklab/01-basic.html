oklch() / oklab() 基础 — 基于人类视觉感知的色彩空间

1. oklch() 基础语法

oklch(L C H) 或 oklch(L C H / A)

L = 亮度 (0-1)，C = 色度 (0-0.4)，H = 色相 (0-360)

2. oklab() 基础语法

oklab(L a b) 或 oklab(L a b / A)

L = 亮度 (0-1)，a = 绿-红轴，b = 蓝-黄轴

红
