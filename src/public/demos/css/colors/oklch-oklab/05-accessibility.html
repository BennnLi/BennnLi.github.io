oklch() 无障碍对比度 — 用 oklch() 确保文字与背景的对比度

1. 推荐的对比度组合

background: oklch(0.2 0.1 250); color: oklch(0.95 0.02 250);

深色背景

浅色文字 — 对比度良好

浅色背景

深色文字 — 对比度良好

技巧：背景和文字的亮度（L）差异越大，对比度越高。建议差异至少 0.5。

2. 高对比度 vs 低对比度

高对比度

亮度差 0.88 — 无障碍友好

低对比度

亮度差 0.1 — 不推荐

注意：低对比度会影响可读性，尤其对视力障碍用户。WCAG 2.1 要求正常文字对比度至少 4.5:1。
