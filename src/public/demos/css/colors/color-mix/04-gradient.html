color-mix() 渐变混合 — 在渐变中使用 color-mix()

1. 线性渐变

background: linear-gradient(90deg, color-mix(in srgb, #1a73e8 100%, white), color-mix(in srgb, #1a73e8 60%, white));

2. 径向渐变

background: radial-gradient(circle, color-mix(in srgb, #28a745 100%, white), color-mix(in srgb, #28a745 60%, white));

3. 混合颜色渐变

background: linear-gradient(135deg, color-mix(in srgb, #1a73e8 80%, #28a745 20%), color-mix(in srgb, #28a745 80%, #1a73e8 20%));
