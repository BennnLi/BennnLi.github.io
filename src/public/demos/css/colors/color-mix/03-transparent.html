color-mix() 透明色 — 用 color-mix() 生成半透明和浅色背景

1. 半透明背景

background: color-mix(in srgb, #1a73e8 50%, transparent);

这是一个半透明的背景，使用 color-mix() 生成。

2. 浅色背景标签

background: color-mix(in srgb, #1a73e8 20%, white);

CSS JavaScript TypeScript HTML Vue

3. 图片叠加层

background: color-mix(in srgb, #000 60%, transparent);

图片标题

这是叠加在图片上的半透明层
