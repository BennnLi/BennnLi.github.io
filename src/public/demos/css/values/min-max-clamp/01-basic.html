min() / max() / clamp() 基础 — 在不同条件下取最合适的值

1. min() — 取最小值

width: min(90%, 600px);

宽度 = min(90%, 600px) — 取两者中较小的值

2. max() — 取最大值

width: max(50%, 300px);

宽度 = max(50%, 300px) — 取两者中较大的值

3. clamp() — 取中间值，限定范围

width: clamp(200px, 50%, 600px);

宽度 = clamp(200px, 50%, 600px) — 最小 200px，最大 600px，理想值 50%

4. 流体字号

font-size: clamp(1.5rem, 4vw + 0.5rem, 3rem);

这是一个流体字号的标题

这是一个流体字号的段落，会根据视口大小自动调整。
