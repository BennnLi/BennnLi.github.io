1. margin 和 padding

margin-inline-start: 16px; padding-inline: 20px; padding-block: 16px;

卡片标题

使用逻辑属性定义的间距和边框，会自动适配不同书写方向。

2. border

border-inline-start: 4px solid #1a73e8;

左边框

使用 border-inline-start 定义的左边框，LTR 时在左侧，RTL 时在右侧。
